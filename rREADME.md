# RAG Evaluation Project

## Project Description

A Document Question Answering application
using Retrieval-Augmented Generation.

## Technology Stack

- Python
- Ollama
- Qdrant
- Sentence Transformers
- PyMuPDF
- RAGAS
- FastAPI
- Pytest

## Project Modules

1. Document Ingestion
2. Document Chunking
3. Embedding Generation
4. Vector Database
5. Retrieval Pipeline
6. LLM Generation
7. Evaluation Harness
8. API Development
