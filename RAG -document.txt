RAG - PIPELINE:
1:Indexing pipeline(offline)
 - Runs when documents are uploaded or updated.
 - steps:
	Document loading
	Text extraction
	chunking
	Embedding
	Vector storage
2:Query pipeline(online)
 - Runs whenever a user asks a question
 - steps:
	Query embedding
	Retrieval
	Reranking
	Context construction
	Generation
	Citation
