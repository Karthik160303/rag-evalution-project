RAG - PIPELINE:
1:Indexing pipeline(offline)
 - Runs when documents are uploaded or updated.
 - steps:
	Document loading
	Text extraction
	chunking
	Embedding
	Vector storage
2:Query pipeline(online)
 - Runs whenever a user asks a question
 - steps:
	Query embedding
	Retrieval
	Reranking
	Context construction
	Generation
	Citation



Phase 1: PDF Documents
		Input documents

Phase 2: Document Ingestion
		Extract, clean and split text into chunks

Phase 3: Embedding Generation
		Convert each text chunk into a numerical vector

Qdrant Vector Database
		Store vectors, text and metadata

Semantic Search
		Find chunks relevant to a user's question

An embedding model converts each sentence into a vector of numbers.
It illustrative values, thet are not actual nomic emabeddings.

Sentence 1: Docker is a containerization platform.
sentence_1 = [0.21, 0.45, 0.89, 0.12]

Sentence 2: Docker helps developers package applications.
sentence_2 = [0.23, 0.42, 0.85, 0.15]

Sentence 3: The weather is very cold today.
sentence_3 = [0.91, 0.13, 0.24, 0.76]

Here we are using the embedding model : ollama nomic-embed-text 
Embedding model is trained to distinguish between text being indexed and text being used to seach.
We use Python's requests library to communicate with Ollama's loacal HTTP API.
